Aquaman

Le compagnon non officiel du jeu de cartes de Poseidon Scans : classement entre amis, quel booster ouvrir, cartes possédées dans les échanges, garantie anti-malchance et vitrine en glisser-déposer. Choisis ton appareil et suis les étapes : 5 minutes au plus.

Installer sur PC

  1. Télécharge l'extension

    Le fichier fait moins de 100 Ko.

    ⬇ aquaman-chromium.zip

  2. Décompresse-le dans un dossier qui restera

    Clic droit sur le fichier → Extraire tout… → Extraire. Range le dossier obtenu dans Documents, par exemple. Ne le supprime pas : l'extension en a besoin pour marcher.

  3. Ouvre la page des extensions

    Tape dans la barre d'adresse, puis Entrée :

    • Chrome, Opera, Vivaldi : chrome://extensions
    • Brave : brave://extensions
    • Edge : edge://extensions

    Active l'interrupteur Mode développeur (en haut à droite, ou à gauche sur Edge).

  4. Charge Aquaman

    Clique sur Charger l'extension non empaquetée et choisis le dossier décompressé (celui qui contient manifest.json). La carte Aquaman apparaît.

    Astuce : épingle l'icône du trident (bouton puzzle 🧩 à droite de la barre d'adresse) pour voir le nombre de boosters à ouvrir.

  5. Mises à jour en un clic (conseillé)

    Dans le dossier de l'extension, double-clique sur installer-mises-a-jour.bat. Ensuite, quand une nouvelle version sort, il suffit de cliquer sur Mettre à jour dans la fenêtre d'Aquaman.

    À refaire seulement si tu déplaces le dossier. Windows peut demander une confirmation : clique sur Informations complémentaires → Exécuter quand même.

  6. Ouvre le jeu

    Va sur poseidon-scans.net/jeu et connecte-toi. La visite guidée d'Aquaman démarre toute seule.

    Ouvrir le jeu ↗

  1. Ajoute Tampermonkey à ton navigateur

    Tampermonkey fait tourner les scripts comme Aquaman. Il est gratuit.

    Firefox Chrome · Brave · Opera Edge

  2. Autorise Tampermonkey (Chrome, Brave, Edge)

    Ouvre la page des extensions (chrome://extensions), clique sur Détails sous Tampermonkey et active Autoriser les scripts utilisateur. Sur les versions plus anciennes, active plutôt le Mode développeur. Rien à faire sur Firefox.

  3. Installe Aquaman

    Clique sur le bouton : Tampermonkey ouvre une page avec un bouton Installer.

    ⬇ Installer aquaman.user.js

  4. Ouvre le jeu

    Va sur poseidon-scans.net/jeu et connecte-toi : la visite guidée démarre. Les réglages sont dans Plus → Réglages.

Installer sur Android

  1. Installe Firefox

    Chrome sur téléphone n'accepte ni les extensions ni les scripts : il faut Firefox (gratuit).

    Firefox sur le Play Store

  2. Ouvre cette page dans Firefox

    Copie l'adresse de cette page et colle-la dans Firefox, pour continuer les étapes là-bas.

  3. Ajoute Tampermonkey à Firefox

    Menu ⋮ → Modules complémentaires → cherche Tampermonkey → Ajouter à Firefox, ou utilise le bouton :

    Tampermonkey pour Firefox

  4. Installe Aquaman

    Touche le bouton : Tampermonkey ouvre une page avec un bouton Installer.

    ⬇ Installer aquaman.user.js

  5. Ouvre le jeu dans Firefox

    Va sur poseidon-scans.net/jeu et connecte-toi : la visite guidée démarre. Dans Ma vitrine, garde le doigt appuyé sur une carte pour la déplacer.

Installer sur iPhone et iPad

  1. Installe l'app Userscripts

    Elle est gratuite et fait tourner les scripts comme Aquaman dans Safari.

    Userscripts sur l'App Store

  2. Active Userscripts dans Safari

    Réglages → Apps → Safari → Extensions → Userscripts : active-la, puis dans Autorisations, choisis Autoriser pour poseidon-scans.net (ou « Tous les sites web »).

  3. Désactive les restrictions

    Réglages → Temps d'écran → Contenu et confidentialité : désactive-le, sinon Safari peut bloquer le téléchargement du script et l'extension.

  4. Installe Aquaman

    Touche ce bouton dans Safari, puis Télécharger : le fichier aquaman.user.js arrive dans tes Téléchargements.

    ⬇ Installer aquaman.user.js

  5. Range le script dans le dossier Userscripts

    Ouvre l'app Fichiers → Téléchargements, garde le doigt sur aquaman.user.js → Déplacer → Sur mon iPhone (ou Sur mon iPad) → Userscripts → Déplacer.

    Si tu as choisi un autre dossier dans l'app Userscripts, mets-le dans celui-là : il est indiqué dans l'app, sous Current directory.

  6. Ouvre le jeu dans Safari

    Va sur poseidon-scans.net/jeu et connecte-toi : la visite guidée démarre.

    Aquaman ne marche pas dans un site ajouté à l'écran d'accueil (app web) : ouvre toujours le jeu dans Safari.

Mettre à jour sur iPhone et iPad

Quand une nouvelle version sort, un cadre « Aquaman … est disponible » s'affiche sur le jeu : touche Installer pour voir ces étapes.

  1. Ouvre Userscripts

    Sur une page du jeu dans Safari, touche ᴀA (ou 🧩) à gauche de la barre d'adresse, puis Userscripts.

  2. Cherche les mises à jour

    Dans le panneau de Userscripts, touche le bouton de recherche de mises à jour (↻), puis mets à jour Aquaman.

  3. Recharge le jeu

    Recharge la page du jeu : les nouveautés de la version s'affichent.

Userscripts ne trouve pas la mise à jour ?

Télécharge le script avec ce bouton (dans Safari), puis Télécharger. Ensuite, app Fichiers → Téléchargements, garde le doigt sur aquaman.user.js → Déplacer → Sur mon iPhone (ou Sur mon iPad) → Userscripts → Déplacer, puis Remplacer. Recharge enfin la page du jeu.

Le fichier s'appelle « aquaman.user 2.js » ? Un ancien était resté dans Téléchargements : supprime-le, puis renomme le nouveau en aquaman.user.js avant de le déplacer.

Questions

Comment se font les mises à jour ?

Script : un cadre te prévient sur le jeu. Sur Android, touche Installer puis Mettre à jour dans Tampermonkey. Sur iPhone et iPad, touche Installer et suis les étapes affichées (ᴀA → Userscripts → recherche de mises à jour) : elles sont aussi dans l'onglet iPhone / iPad ci-dessus. Extension : une notification te prévient, puis clique sur Mettre à jour dans la fenêtre d'Aquaman (après avoir lancé une fois installer-mises-a-jour.bat), ou remplace le dossier par la nouvelle version.

Mes données sont-elles envoyées quelque part ?

Aquaman lit le jeu avec ta session, comme le site lui-même ; ta session n'est jamais envoyée ailleurs. Pour partager la garantie anti-malchance et tes séries favorites entre tes appareils, il envoie à son relais ton identifiant de joueur, pour chaque booster ouvert l'heure et la meilleure rareté obtenue (avec la carte et le pack pour une SSR, UR ou SEC), la liste de tes séries favorites, et ton stock de Perles pour le classement. Rien d'autre, et chaque partage se coupe dans les réglages.

Pourquoi pas Chrome sur téléphone ?

Chrome pour Android et iPhone n'accepte aucune extension ni aucun script. Firefox (Android) et Safari avec Userscripts (iPhone, iPad) le permettent.

Comment désinstaller ?

Extension : Supprimer sur sa carte dans la page des extensions, puis supprime son dossier. Script : supprime Aquaman dans Tampermonkey ou dans l'app Userscripts.
